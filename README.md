# CAPSTONE-PROJECT-Oloruntoba-Christopher-
DSML: CAPSTONE PROJECT
Project Overview
This project builds a predictive machine learning model to estimate the probability that a building will have at least one insurance claim during the insured period based on building characteristics.

Problem Type
Binary Classification

Target Variable
- Claim = 1 → At least one claim
- Claim = 0 → No claim

Dataset
The dataset contains building-level characteristics and insurance claim history.

Models Implemented
- Logistic Regression
- Random Forest
- Gradient Boosting

Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

Key Results
Tree-based models performed better than linear models, with Gradient Boosting achieving the highest ROC-AUC.
